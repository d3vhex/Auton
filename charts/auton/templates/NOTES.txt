Auton {{ .Chart.AppVersion }} is installed in namespace {{ .Release.Namespace }}.

The API is a ClusterIP service; the UI is served at "/":

  kubectl -n {{ .Release.Namespace }} port-forward svc/auton 8080:8080
  open http://localhost:8080/

Paste the bearer token into the UI ("Set token"):

  kubectl -n {{ .Release.Namespace }} get secret {{ default "auton-api-token" .Values.agent.auth.existingSecret }} \
    -o jsonpath='{.data.token}' | base64 -d

Check the autonomous ops controller:

  kubectl -n {{ .Release.Namespace }} logs deploy/auton-ops --tail=50
  kubectl -n {{ .Release.Namespace }} get incidents   # no CRD: use GET /incidents
