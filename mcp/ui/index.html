API access token

    

      The page you are looking at contains no data and is served without a
      token. Everything that does something — running a task, reading
      incidents or audit records, changing provider settings — goes through an
      API that can execute shell commands and patch workloads in your cluster.
      That is why it requires a bearer token.
    

    
Where do I get it?

    

      
kubectl -n auton get secret auton-api-token -o jsonpath='{.data.token}' | base64 -d

      
    

    
or run ./scripts/install.sh --show-token.

    
Where is it stored?

    

      Only in this browser's localStorage. It is never embedded in
      the page and is sent only to this origin (no third-party requests). Use
      “Forget token” to remove it.
